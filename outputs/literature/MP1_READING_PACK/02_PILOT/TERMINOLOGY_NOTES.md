# Pilot terminology notes

| Term | Pilot source use | Reading caution |
|---|---|---|
| pre-slip/jamming | M17/M18: below μp, cohesive state | Model/state label; retain topology and pressure. |
| partial/half slipping | M17/M18: local slip with remaining cohesive region | Not a directly measured local map unless instrumented. |
| full slip/full slipping | M17/M18 limiting state | Model state, not universal physical uniform slip. |
| slip rigidity k | M22 laminated-beam interface parameter | Not identical by definition to μ or traction. |
| EBS/EIeff | M22 equivalent cable stiffness | Depends on geometry, tension and k. |
| superelastic plateau | M26 axial NiTi transformation response | Not bending stiffness or M–κ. |
| shakedown | M26 cycle-dependent response evolution | Separate material, topology and contact history. |
